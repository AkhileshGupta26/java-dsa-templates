Tier 1 (Amazon's absolute favorites)
1. Arrays + Simulation ⭐⭐⭐⭐⭐

This is Amazon's biggest strength.
Not "reverse array."
Instead, implementation-heavy questions like:

Warehouse inventory
Robot movement
Delivery routes
Server allocation
Customer requests

Almost every OA contains at least one implementation-based array problem.

Examples:

Rotate
Prefix/Suffix
Frequency
Rearrangement
Simulation

Probability: ~90%

2. HashMap ⭐⭐⭐⭐⭐

Amazon loves counting.

Questions like:

Frequency
Pair counting
Distinct elements
Duplicate detection

Nearly every OA has a HashMap solution somewhere.

Examples

Two Sum
Subarray Sum
Group Anagrams
Frequency Sort

Probability: ~75%
